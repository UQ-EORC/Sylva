    PointCloud and Raster¶

    sylva.pointcloud ¶

    Numpy-backed point cloud container.

    PointCloud dataclass ¶

    A set of 3D points with optional per-point attributes.

    Every function in Sylva that takes points takes a PointCloud and returns a new one; nothing is modified in place. Coordinates are metres in whatever frame the data came in (scanner, project or projected CRS).

    Parameters:

    Name Type Description Default
    xyz ndarray

    (N, 3) array of coordinates, stored as C-contiguous float64.

    		 required
    attrs dict[str, ndarray]

    Mapping of attribute name to a length-N array (intensity, classification, height, ...). Names follow laspy conventions so LAS files round-trip.

    		 dict()
    crs str | None

    Coordinate reference system of xyz, or None when unknown: an EPSG code ("EPSG:7855"; an integer is turned into that form), a PROJ string or WKT. sylva.read sets it from LAS/LAZ headers and sylva.write stores it in LAS/LAZ files. It is carried through subsetting, transform, translate, rotate, recentre and concatenate unchanged, so after a local shift it describes the frame the offset returns to; sylva.coords.reproject changes it.

    		 None

    Raises:

    Type Description
    ValueError

    If xyz is not (N, 3), an attribute is not length N or crs is not a string, integer or None.
    Notes

    Attributes Sylva itself writes and reads:

    Name Written by Meaning
    classification sylva.ground.classify_ground_csf ASPRS codes, 2 = ground
    height sylva.ground.normalize_height height above the DTM (m)
    tree_id you, from sylva.trees.segment_trees tree number, -1 unassigned
    scan_id sylva.registration.merge_scans index of the source scan
    nx, ny, nz ray-cloud PLY vector from point to sensor

    Indexing with a boolean mask, integer array or slice returns a subset with all attributes: cloud[cloud.z > 1.3].

    Examples:

    >>> import numpy as np, sylva
>>> cloud = sylva.PointCloud(np.random.rand(100, 3), {"intensity": np.ones(100)})
>>> tall = cloud[cloud.z > 0.5]

    translate ¶

    translate(dx: float, dy: float, dz: float = 0.0) -> PointCloud

    Shift every point by a constant offset.

    Parameters:

    Name Type Description Default
    dx float

    Offset in the units of the coordinates (m).

    		 required
    dy float

    Offset in the units of the coordinates (m).

    		 required
    dz float

    Offset in the units of the coordinates (m).

    		 required

    Returns:

    Type Description
    PointCloud

    Shifted copy with the same attributes and crs. Each coordinate gets one addition, so shifting back by the negated offset returns the original to within one rounding, and exactly for whole-metre offsets of millimetre data.

    Raises:

    Type Description
    ValueError

    If an offset is not finite.

    Examples:

    >>> local = cloud.translate(-500_000, -6_900_000)

    rotate ¶

    rotate(angle_deg: float, axis: str | Iterable[float] = 'z', about: Iterable[float] | None = None) -> PointCloud

    Rotate every point about an axis.

    Parameters:

    Name Type Description Default
    angle_deg float

    Angle in degrees, positive counter-clockwise when looking down the axis towards the origin (right-handed): 90 about "z" turns +x into +y.

    		 required
    axis str | Iterable[float]

    "x", "y", "z" or any 3-vector (normalised here).

    		 'z'
    about Iterable[float] | None

    A point (x, y, z) on the axis; the origin if None. Rotate about the plot centre, or recentre first, to keep projected coordinates from swinging far away.

    		 None

    Returns:

    Type Description
    PointCloud

    Rotated copy with the same attributes and crs. Direction-like attributes (nx, ny, nz) are not rotated. Multiples of 90 degrees are exact.

    Raises:

    Type Description
    ValueError

    If the angle, axis or centre is not finite, the axis is zero or an unknown name, or about does not have three values.

    Examples:

    >>> turned = cloud.rotate(30, about=cloud.xyz.mean(axis=0))

    recentre ¶

    recentre(origin: Iterable[float] | None = None) -> tuple[PointCloud, np.ndarray]

    Move the coordinates close to zero.

    Projected coordinates in the millions of metres leave float32 (and many viewers and meshing tools) with centimetre precision; local coordinates keep it.

    Parameters:

    Name Type Description Default
    origin Iterable[float] | None

    Point that becomes (0, 0, 0). By default the minimum corner of the (finite) points rounded down to whole metres, so the offset is exact and short.

    		 None

    Returns:

    Name Type Description
    cloud PointCloud

    Shifted copy with the same attributes and crs.
    offset ndarray

    Length-3 offset that undoes the shift: cloud.translate(*offset) gives the original coordinates.

    Raises:

    Type Description
    ValueError

    If origin is not three finite numbers.

    Examples:

    >>> local, offset = cloud.recentre()
>>> restored = local.translate(*offset)

    sylva.raster ¶

    Georeferenced 2D grid for DTMs and CHMs.

    Raster dataclass ¶

    A regular 2D grid in map coordinates, used for DTMs and CHMs.

    data[row, col] covers x from xmin + col * resolution and y from ymin + row * resolution, so row 0 is the southern edge (the array is upside down compared with an image). to_geotiff and to_ascii_grid flip it to the usual north-up order on export.

    Parameters:

    Name Type Description Default
    data ndarray

    (rows, cols) values; NaN marks cells with no data.

    		 required
    xmin float

    Coordinates of the south-west corner of the grid (not of the first cell centre).

    		 required
    ymin float

    Coordinates of the south-west corner of the grid (not of the first cell centre).

    		 required
    resolution float

    Cell size in the units of x and y (m).

    		 required
    crs str | None

    Optional CRS string ("EPSG:28355") used by to_geotiff. Sylva never reprojects.

    		 None

    shape property ¶

    shape: tuple[int, int]

    (rows, cols) of data.

    xmax property ¶

    xmax: float

    Eastern edge of the grid.

    ymax property ¶

    ymax: float

    Northern edge of the grid.
