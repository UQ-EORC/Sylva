    Function index¶

    Every public class, method and function, grouped by module. Each name links to its full entry: parameters with units and defaults, return values, exceptions, and notes on accuracy where the method has been benchmarked.

    Conventions used throughout:

    • Lengths are metres, areas m², volumes m³, densities m² m⁻³ (area) or m³ m⁻³ (wood volume). Angles are degrees unless a parameter says radians.
    • Point arrays are (N, 3) float64. Voxel arrays are (nz, ny, nx), and grid shape properties are (nx, ny, nz).
    • Functions return new objects and never modify their inputs. The exceptions are GapProfile.add_scan, RayVoxelGrid.add_wood_volume and trees.tree_heights, which say so.
    • Anything random takes a seed, so a run can be repeated exactly.
    • Errors: bad files raise OSError, bad arguments raise ValueError, and missing attributes raise KeyError or ValueError with the attribute's name.

    sylva.canopy¶

    Name Kind Summary
    VoxelGrid class Point counts on a regular 3D grid; build with voxelize.
    VoxelGrid.occupied property Boolean (nz, ny, nx), True where a voxel holds at least one point.
    VoxelGrid.shape property Grid size as (nx, ny, nz) (the reverse of counts.shape).
    VoxelGrid.z_levels method Bottom z of each voxel layer.
    VoxelGrid.occupied_centers method Centres of the occupied voxels, e.g. for plotting.

    vertical_profile function Point counts by height above ground.

The number of pulses fired per ring comes from the angular scan pattern (see Shots.expected_per_zenith); a fired pulse with no echo above min_height is a gap. Pass the shots in the scanner frame, or pulses_per_line from the scanner-frame shots.
    lai_from_gap_fraction function Effective PAI from directional gap fraction.
    canopy_cover function Canopy cover from a canopy height model.
    DensityGrid class Ray-traced voxel statistics (raycloudtools / Lowe et al. 2021 style).
    DensityGrid.z_levels method Bottom z of each voxel layer.
    DensityGrid.centers method Voxel-centre coordinates.
    DensityGrid.height_above method Height of each voxel centre above the terrain.
    DensityGrid.pai property Plant area index: the layer means summed over height (m² m⁻²).
    DensityGrid.mask_ground method Remove ground voxels so terrain returns do not count as plant material.
    DensityGrid.profile_above_ground method Plant area density by height above the terrain.
    density_grid function Ray-trace pulses through a voxel grid and estimate plant area density.
    fit_ground_plane function Ground plane z = a x + b y + c through the lowest point of every cell (m) grid cell, optionally within radius of centre (xy), fitted with Huber-weighted least squares so tree bases and pits pull little (after Calders et al. 2014).
    fired_pulses_per_ring function Pulses a RIEGL scan fired into each zenith ring, for streams without the pulses that returned nothing (RiVLib). shots_scanner in the scanner frame, read with shot_stride.
    fired_pulses_from_points function Pulses a scan fired into each zenith ring, from its returns alone.
    GapProfile class Gap probability by zenith ring, azimuth sector and height above ground, pooled over scans (Jupp et al. 2009), and what follows from it.
    GapProfile.empty method Start an empty profile.
    GapProfile.add_scan method Add one scan position's pulses; echo_heights above ground, one per echo. Without fired_per_ring the shots must include the pulses that returned nothing (e.g. Shots.fill_missing or a ray cloud).
    GapProfile.heights property Top of each height bin (m): the profile at z counts returns below it.
    GapProfile.zenith property Ring centres (deg).
    GapProfile.pgap method Gap probability by ring and height.
    GapProfile.pai_profile method Cumulative plant area index below each height (effective, not corrected for clumping).
    GapProfile.pavd_profile method Plant area volume density: the height derivative of pai_profile.
    GapProfile.clumping method Lang & Xiang (1986) clumping index at the ring holding zenith: ln(mean P) / mean(ln P) over every (scan, azimuth sector) segment. 1 is random foliage; below 1 clumped.
    GapProfile.report method Plot summary: effective PAI (hinge, linear, weighted), mean leaf angle from the linear fit, clumping index and clumping-corrected hinge PAI, canopy height (where the hinge PAI profile reaches top_fraction of its total), canopy closure at 57.5 deg, cover at the steepest ring measured, and the profiles.
