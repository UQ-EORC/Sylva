    kabsch ¶

    kabsch(source: ndarray, target: ndarray) -> np.ndarray

    Best rigid transform between paired points (Kabsch 1976; Umeyama 1991, no scale).

    Use with matched targets (reflectors, tie points) to register scans.

    Parameters:

    Name Type Description Default
    source ndarray

    (N, 3) corresponding points, N >= 3 and not collinear.

    		 required
    target ndarray

    (N, 3) corresponding points, N >= 3 and not collinear.

    		 required

    Returns:

    Type Description
    ndarray

    (4, 4) matrix mapping source onto target in the least squares sense.

    icp ¶

    icp(source: PointCloud, target: PointCloud, init: ndarray | None = None, max_correspondence_distance: float = 0.5, max_iterations: int = 50, tolerance: float = 1e-06, method: str = 'point', trim: float = 1.0, normal_k: int = 12) -> tuple[np.ndarray, dict]

    Iterative closest point.

    method is "point" (point-to-point, Besl & McKay 1992) or "plane" (point-to-plane, Chen & Medioni 1992, linearised as in Low 2004; normals from target.attrs['nx','ny','nz'] if present, else PCA). trim keeps that fraction of closest correspondences per iteration (trimmed ICP for partial overlap, Chetverikov et al. 2002).

    Parameters:

    Name Type Description Default
    source PointCloud

    Cloud to move.

    		 required
    target PointCloud

    Fixed reference cloud.

    		 required
    init ndarray | None

    Starting (4, 4) transform (e.g. from the SOP or kabsch); ICP only converges from a start within about max_correspondence_distance.

    		 None
    max_correspondence_distance float

    Pairs further apart (m) are ignored.

    		 0.5
    max_iterations int

    Iteration limit.

    		 50
    tolerance float

    Stop when the RMSE changes less than this.

    		 1e-06
    method ('point', 'plane')

    Error metric; point-to-plane converges faster on stems and ground.

    		 "point"
    trim float

    Fraction of pairs kept (0-1).

    		 1.0
    normal_k int

    Neighbours for PCA normals with "plane".

    		 12

    Returns:

    Name Type Description
    transform ndarray

    (4, 4) matrix mapping source onto target.
    info dict

    rmse (m), iterations and n_correspondences.
    Notes

    Thin both clouds to 2-5 cm first; ICP on full-density TLS is slow and no more accurate. Check the result with sylva.quality.stem_noise.
